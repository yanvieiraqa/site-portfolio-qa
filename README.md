Site de portfólio e currículo de **Yan Vieira**, QA Júnior com foco em testes manuais e de API. O site apresenta meus projetos de qualidade de software, minhas habilidades e formas de contato.

## O que tem no site

- **Início:** card animado de status dos testes, com contadores e anéis de progresso, e logs simulados

- **Habilidades e ferramentas:** testes manuais, casos de teste, testes de API, Jira, Git/GitHub e documentação
- **Projetos em destaque:**
  - Testes de API REST (ServeRest) com Postman
  - Projeto de QA no Jira (simulação de mercado)

- **Experiência e formação**, com cursos
- **Metodologia de trabalho:** planejamento, casos de teste, execução, registro de bugs, reteste e relatório final
- **Contato:** LinkedIn, GitHub, e-mail e WhatsApp, com formulário que monta a mensagem pronta
- Botão para **baixar o currículo** em PDF

## Como rodar localmente

Abra o `index.html` no navegador. Para testar como se estivesse hospedado (por exemplo, o download do currículo), use um servidor local na pasta do projeto:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
